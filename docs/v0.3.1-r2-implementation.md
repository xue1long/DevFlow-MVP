# DevFlow v0.3.1-r2 实施方案(最简替代版)

> **核心思路**:每个修补都走「第一性原则」最简替代,绝不扩 storage schema,绝不破哈希链,绝不引入新依赖,绝不破坏隐性兼容。

### 工作项 #2 — P1-5:stub 红线透明化(0.25d)

#### 4 角色审计核心问题
> "5 条 stub 暴露后,audit 输出变 5 违规,误以为项目违规暴涨"(角色1 P2-1)
> "stub 暴露让'已审计'承诺降级"(角色2 P1-5 / 角色3 P1-V31-2)
> "audit() 重构 + RedLineViolation 加 status 字段 = 重蹈 v0.3 INDEX 覆辙"(角色3)

#### 最简替代:**不改 `redline_auditor.py`,只在 `cli.py` 输出里区分**

**关键发现**:`RedLineViolation` 已有 `skip: bool` 字段;`redline_auditor.py:38-43` 对 `circular_dep` 已经返回 `skip=True`。**5 条 stub 函数**(`_check_skip_phase` 等)返回 `[]`,**所以根本不在 violations 列表里**。

**修复策略**:
1. `redline_auditor.py` 加一个 `not_implemented_rules` 方法,列出所有"配置有但无 checker"的规则名
2. `cli.py` 的 `audit` 命令同时返回 `violations` + `not_implemented` + `covered_rules`

**改动 `redline_auditor.py`**(只加方法,不重构 audit()):

```python
def audit(self) -> list[RedLineViolation]:
    """执行全量红线扫描(不变)"""
    violations: list[RedLineViolation] = []
    for red_line in self.config.red_lines:
        if red_line.mvp_skip:
            violations.append(RedLineViolation(
                red_line.name,
                f"红线 '{red_line.name}' 在 MVP 中跳过检测 (mvp_skip: true)",
                skip=True,
            ))
            continue
        checker = getattr(self, f"_check_{red_line.name}", None)
        if checker is None:
            violations.append(RedLineViolation(
                red_line.name,
                f"红线 '{red_line.name}' 缺少自动检测实现 (not_implemented)",
                skip=True,
            ))
            continue
        violations.extend(checker())
    return violations
```

**注意**:这段**代码已在 r1 方案中存在**,但**r1 方案同时修改了 `RedLineViolation.__init__` 加 `status` 字段,导致 `TypeError`(角色1 P1-2)**。r2 **严格只改 `audit()` 方法体**,不改 `__init__`、不改 `to_dict()`、不改 model 文件。`status` 字段通过 `skip=True` + `message` 文本隐含(`message` 里已写明 "not_implemented" 或 "mvp_skip")。

**改动 `cli.py`**(`audit` 命令):

```python
@app.command()
def audit():
    """执行红线审计(P1-5 简化版:返回 not_implemented 列表区分 stub)"""
    storage = FSBackend(_get_root())
    config = _get_config()
    git = SystemGitPort(_get_root())
    auditor = RedLineAuditor(storage.root, config, git=git)
    violations = auditor.audit()

    real = [v.to_dict() for v in violations if not v.skip]
    skipped = [v.to_dict() for v in violations if v.skip]

    _output({
        "ok": True,
        "violations": real,         # 仅真实违规
        "skipped": skipped,         # mvp_skip + not_implemented 都在这
        "total_real": len(real),    # 真实违规数(替代旧的 total)
        "total_skipped": len(skipped),
        "coverage": {
            "configured": len(config.red_lines),
            "implemented": len(real) + len(skipped),  # 包括 mvp_skip 视为"已配置"
            "not_implemented": len([v for v in skipped if "not_implemented" in v["message"]]),
        },
    })
```

#### 兼容性影响

- ✅ **不破坏 schema**:`RedLineViolation` 字段不变;`total` 字段移除(破坏),改 `total_real`
- ⚠️ **CLI 输出破坏**:`total` → `total_real`,但 CLI 文档明确说"v0.3.1 是补丁版本"
- ✅ **零 model 文件变更**:`model/redline.py` 原本就不存在(角色4 F-03)
- ✅ **零新字段**:`__init__` 签名不变

#### 测试设计(`tests/test_p1_5_simplified.py`,2 个用例)

**当前配置**(`sop.default.yaml:31-36`)保持不变(已被工作项 #1 改为 `enabled: false`):

```yaml
ci_green:
  command: "echo ci-check-placeholder && exit 0"
  blocking: false
  enabled: false
  note: "默认禁用。MVP 阶段 advisory 模式,真实 CI 接入留 v0.4"
```

**新增 CLI 命令**(`cli.py`):

```python
@app.command()
def ci_status():
    """P1-9 简化版:显示当前 ci_green 配置状态与占位提示"""
    config = _get_config()
    gate = config.get_gate("ci_green")
    if gate is None:
        result = {"ok": False, "message": "ci_green 门禁未配置"}
    elif not gate.enabled:
        result = {
            "ok": True,
            "status": "disabled",
            "message": "ci_green 禁用中(占位命令不生效)",
            "hint": "启用真实 CI:在 sop.yaml 设置 gates.ci_green.enabled: true 并配置真实 command",
        }
    elif "placeholder" in (gate.command or "").lower():
        result = {
            "ok": True,
            "status": "placeholder",
            "message": "ci_green 使用占位命令,实际未跑真实 CI",
            "hint": "接入真实 CI:修改 sop.yaml gates.ci_green.command",
        }
    else:
        result = {
            "ok": True,
            "status": "configured",
            "command": gate.command,
            "blocking": gate.blocking,
        }
    _output(result)
```

#### 兼容性影响

- ✅ **零配置变更**(ci_green 命令保持占位 echo)
- ✅ **零新依赖**(不引入 pytest-cov)

- ✅ **新命令**:`ci-status` 不冲突(`ci-greem` 已通过 `-` 命名)

### 工作项 #4 — P1-13:review ↔ ledger 用文件系统 JOIN(0.5d)

#### 4 角色审计核心问题
> "P1-13 LedgerEntry 加字段破坏哈希链"(角色1 P0-2 / 角色2 P0-1 / 角色3 P0-V31-2 / 角色4 P1-03)
> "P1-13 重蹈 v0.3 INDEX 覆辙"(角色3 / 角色4 P1-07)
> "P1-13 实际有 5 处 append_ledger"(角色1 P0-1 / 角色3 P0-V31-1)
> "P1-13 加 actor 字段永不写入,Speculative Generality"(角色3 P1-V31-5)

#### 最简替代:**不扩 schema,只新增 CLI 用现有接口做 JOIN**

**核心思想**:`review_store` 已有 `list_reports(spec_id)` 和 `list_spec_ids()`;`storage.get_ledger()` 已返回带 `entries` 的 dict。**完全不需要 LedgerEntry 加字段**,JOIN 现有数据即可。

**新增 CLI 命令**(`cli.py`):

```python
@app.command()
def review_audit():
    """P1-13 简化版:扫描 ledger 的 REVIEW/FIX/ESCALATE 条目,与 review_store 报告做 JOIN

    不修改 LedgerEntry schema(避免破坏哈希链)。
    不修改 review_engine.py 写入点(避免 5 处漏算风险)。
    """
    storage = FSBackend(_get_root())
    review_store = ReviewStore(_get_root())

    ledger = storage.get_ledger()
    entries = ledger.get("entries", [])

    # 收集所有 REVIEW/FIX/ESCALATE 条目,按 (spec_id, round) 关联
    report_keys = set()
    for spec_id in review_store.list_spec_ids():
        for report in review_store.list_reports(spec_id):
            # report.id 格式: f"r{round}",按 spec 限定
            report_keys.add((spec_id, report.round))

    # 扫描 ledger:每个 REVIEW action 应该有对应 (spec_id, round) 在 report_keys
    reviewed_orphans = []
    for entry in entries:
        if entry.get("action") not in ("review", "fix", "escalate"):
            continue
        # 从 details 解析 round(已有"评审 R1"等可解析信息)
        # 若解析不到 round 则跳过(可能是旧账本无 round)
        details = entry.get("details", "")
        round_match = re.search(r"R(\d+)", details)
        if not round_match:
            continue
        round_num = int(round_match.group(1))
        # 当前 spec 由 ledger 顶层 current_spec_id 决定(简化)
        spec_id = ledger.get("current_spec_id")
        if spec_id and (spec_id, round_num) not in report_keys:
            reviewed_orphans.append({
                "entry_index": entries.index(entry),
                "action": entry["action"],
                "details": details,
                "missing_report": f"{spec_id}/r{round_num}",
            })

    _output({
        "ok": True,
        "total_ledger_entries": len(entries),
        "total_review_actions": len([e for e in entries if e.get("action") in ("review", "fix", "escalate")]),
        "total_reports": sum(len(review_store.list_reports(s)) for s in review_store.list_spec_ids()),
        "orphans": reviewed_orphans,  # ledger 说有 review 但 store 没对应报告
        "missing_in_ledger": [],       # 反向:有报告但 ledger 没记录(v0.4 再做)
    })
```

#### 兼容性影响

- ✅ **零 schema 变更**(`LedgerEntry` 字段不变 → 哈希链完整)
- ✅ **零写入路径变更**(`review_engine.py` 4 处 `append_ledger` 一行不改)
- ✅ **零 actor 字段**(`Speculative Generality` 陷阱规避)
- ✅ **零新接口**(复用 `review_store.list_reports` / `storage.get_ledger`)
- 🔧 **新 CLI**:`review-audit` 用 `-` 命名,不与 `review` 冲突
